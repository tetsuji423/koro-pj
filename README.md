# ハリネズミのアイコン素材

見本の番号順に16個、各5コマ、合計80枚のPNGを生成しました。

- 保存先: `assets/hedgehog/originals/icon_01/frame_01.png` ～ `icon_16/frame_05.png`
- サイズ: 各1254×1254px（180×180pxへの縮小前の原画像）
- 背景: アルファ透過
- コマごとに表情・姿勢・装飾に変化があります。
- `assets/hedgehog/manifest.json` に対応表と画素のSHA-256を記録しています。
- 80枚すべてが正方形・透過あり・画素の完全重複なしであることを確認済みです。

番号: 01笑顔、02大笑い、03涙、04驚き、05睡眠、06ハート、07お辞儀、08後ろ姿、09においを嗅ぐ、10照れる、11怒る、12走る、13舌なめずり、14指を甘噛み、15トイレ、16あくび。

画像はコマごとに生成されているため、輪郭・大きさ・細部には揺れがあります。アニメーションファイルへの結合と180×180pxへの縮小は未実施です。
